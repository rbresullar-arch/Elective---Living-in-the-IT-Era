Downloadable Examinations

You can take an examination in one of two ways:

  1. Online — tap the examination's name. It opens on this page and needs internet.
  2. Offline — tap Download … (offline). The file saves to your device and works without internet.
Choose only one. Each examination accepts one attempt, and your QR code is your record.

Opening a downloaded examination

The file name ends in _exam_ITEra.html (for example, prelim_exam_ITEra.html).

Android

  1. Open this page in Chrome and tap the download button.
  2. In Chrome, tap ⋮ → Downloads.
  3. Tap the examination file. It opens in Chrome.

iPhone / iPad

  1. Install Microsoft Edge from the App Store.
  2. Open this page in Edge (not Safari), tap the download button, then tap Download.
  3. In Edge, tap ⋯ → Downloads, then tap the examination file.
  4. Do not open the file from the Files app. The examination will not work there.

Windows / Mac

  1. Click the download button. The file saves to your Downloads folder.
  2. Double-click the file, or right-click → Open with → Chrome or Edge.
Keep the file until your QR code is saved. To resume, open the same file in the same browser. Do not clear your browser data during the examination.
