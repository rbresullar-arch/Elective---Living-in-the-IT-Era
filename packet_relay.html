Route the packet

Data crosses a network in small packets. IP moves each packet from router to router. TCP waits for an ACK (acknowledgement) and resends the packet if it does not arrive.

  1. Read the task: send the packet from one node to another.
  2. Tap one node in every row, bottom to top, to build the path. Then press Send.
  3. Green hops are right; red hops are wrong. A wrong path gets no ACK: fix it and press Resend.
  4. 5 puzzles. Each solved puzzle adds a router row.
